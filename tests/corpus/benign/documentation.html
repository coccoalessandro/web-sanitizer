Pipeline Configuration Manual

This document details the configuration parameters available for the batch processing engine.

Worker Thread Scheduling

Worker threads poll incoming jobs concurrently from a shared channel. Each worker maintains an independent parsing context to maximize L1/L2 cache locality.

Recommended settings:

For I/O bound workloads: 2x available physical CPU cores.

For compute-heavy parsing: 1x physical CPU cores.

Memory Safety Guarantees

All input streams are bounded using streaming capacity limits to prevent heap exhaustion. Refer to Hyper Project for foundational networking concepts.

Notice: Always configure network timeouts appropriately when dispatching remote jobs.
